# basecoat 零构建只有整包一条路，base 版缺皮肤全站裸奔

## 场景

PM 希望按官方文档 `@import "basecoat-css/base.css" + components/tabs.css + styles/lyra.css` 的方式按组件引入样式，并指定 Lyra 为默认主题。

## 踩坑

核实 basecoat-css@1.1.0 包结构：`components/*.css`、`styles/*.css` 全是 Tailwind v4 源码（@apply/@theme 指令），浏览器无法加载；编译产物只有整包级。误信「basecoat-base.cdn.min.css = base tokens + utilities + component structure」的描述换成两层方案，结果全站组件裸奔——**组件皮肤规则（配色/边框/背景那半截 CSS）在风格包内，base 版只有结构**；同时 lyra 变体把 `.input` 锁 32px（通用版是 36px），不同风格包尺寸口径不同源。

## 修正

vendor 统一用 `basecoat-lyra.cdn.min.css`（Lyra 风格编译在内）+ `/theme.css`（zpm 换肤 token 覆盖优先级更高，其他主题照常可切）；已写入宪法硬性规则 4（PROP-20261031-02，v1.3.0）。组件尺寸口径以当前 vendored 整包实测为准，禁止沿用记忆中的通用版数值。

## 应用规则

零构建项目的 basecoat 引入只用官方整包（按主题选 `basecoat-<style>.cdn.min.css`），禁换 basecoat-base 等无风格包变体；「按组件引入 CSS」仅存在于 Tailwind 构建项目，别再尝试；组件尺寸/类名契约改动前先 grep vendor css 实测。
