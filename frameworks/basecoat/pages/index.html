这是一个由 zpm 生成并驱动的数据原型项目：表结构同步、页面原型、主题配置都在本地跑通， 用自然语言 + opencode 命令即可持续迭代，改完刷新即见。

  1. 同步数据：在 zpm.config.yaml 的 sync.tables 填入表（可让 agent 用 dbx 探查），然后 zpm sync && zpm serve
  2. 长出页面：在 opencode 里说「用 zpm-brainstorming 帮我想一个xx页面」

从这里开始

工作台 常用命令与页面模板一览，日常开发从这里开始 数据字典 已同步表的结构与字段说明，写页面前对照用 主题配置 在线调整配色 / 圆角 / 字体，可导出主题 CSS 长期生效

提示：左侧菜单可随时切换页面；修改 pages/ 下的 HTML 后刷新浏览器即见效果。
