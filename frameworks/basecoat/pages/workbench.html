原型工作台

用自然语言 + opencode 命令开发原型。三步上手：① 在 zpm.config.yaml 的 sync.tables 填入表（可让 agent 用 dbx 探查）→ ② zpm sync && zpm serve → ③ opencode 里说「用 zpm-brainstorming 帮我想一个xx页面」。

命令速查

悬浮命令所在行，点右侧图标复制

命令用途
zpm-brainstorming头脑风暴：逐项确认页面效果后进入实现
zpm-new-page新建页面（描述你想要的效果即可）
zpm-new-page-tpl从指定模板创建页面（list/form/detail/dashboard/board）
zpm-page-review按宪法规则走查页面
zpm-try-component试验 basecoat 组件效果
zpm-asset-save / list / use资产库：沉淀 / 浏览 / 复用（全局 ~/.zpm/assets）
zpm-lesson-save / list经验库：沉淀 / 浏览踩坑教训（全局 ~/.zpm/lessons）
zpm-law-propose / adopt宪法修正提案 / 采纳
zpm-db-info生成数据字典页

页面模板

示例 prompt 同样悬浮复制，可直接贴进 opencode

模板适合示例 prompt
crud实体增删改查用 crud 模板给我做一个 XX 管理页（增删改查 + 搜索筛选 + 导出）
tpl-listCRUD 列表用 tpl-list 给我做一个客户列表页，展示 name/阶段/金额
tpl-form新建/编辑表单用 tpl-form 做客户新建页
tpl-detail单记录详情用 tpl-detail 做客户详情页
tpl-dashboardKPI + 图表用 tpl-dashboard 做销售概览
tpl-board看板拖拽用 tpl-board 做商机看板，按阶段分列
